# Pet Shop Management System

A simple web application built with **Flask** as part of a mini challenge to practice basic web development concepts. The application demonstrates CRUD operations for managing pet shop data using the Flask framework.

## Features

- View pet data
- Add new pets
- Edit existing pet information
- Delete pet records
- Simple Flask routing
- Basic HTML templates

## Technologies Used

| Item | Details |
|:-----|:--------|
| Language | Python |
| Framework | Flask |
| Frontend | HTML, CSS |
| Database | SQLite |

## How to Run

1. Clone this repository.

```bash
git clone https://github.com/shiroshi1711/flask_challenge
```

2. Install the required dependencies.

```bash
pip install -r requirements.txt
```

3. Start the Flask application.

```bash
python main.py
```

4. Open your browser and navigate to:

```text
http://127.0.0.1:5000
```
